# Shopping Mall Project

This is a Java Server Pages (JSP) Shopping Mall project.

## Directory Structure
- `/src/main/java/com/example/dao/`: Contains DAO classes.
- `/src/main/webapp/`: Contains JSP files.
- `/src/main/resources/`: Contains configuration files.
- `/sql/`: Contains database setup SQL file.

## Configuration Files
- `web.xml`: Configuration for web application.
- `persistence.xml`: JPA persistence configuration.

## Note
Make sure to configure your database connection properly in the configuration files.
